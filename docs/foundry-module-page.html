Character Builder (DnD 5e)

Guided D&D 5e Character Creation, Level Up, Multiclass, Epic Boon gifts, dynamic compendium sources, and class-aware rest management for Foundry VTT 14.

Character Builder uses official D&D5e documents and native Advancements as its rules spine. Players make guided choices in protected drafts, review the result, and apply the completed transaction to the live Actor only after final confirmation.

Compatibility: Foundry VTT 14.367, D&D5e 5.3.3, Player's Handbook 2024, SRD 5.2 Modern, SRD 5.1 Legacy, and compatible third-party Item compendiums.

Guided Character Creation

Review any confirmed creation step freely. A protected confirmation appears only when a player actually changes a confirmed Ability Score, Background, Species, Class, spell choice, or starting-equipment choice, and the affected native choices can then be completed again safely.

Open an empty Player Character Actor and use the gold launcher directly on the sheet. The guided flow covers Origins, Species, Background, Ability Scores, Class, class choices, Spell Selection, Starting Equipment, Shop, Review, and protected Finish Character application.

Level Up and Multiclass

Game Masters can grant progression individually or distribute it to multiple eligible Actors through Character Builder Tool. Players receive a Level Up arrow on their sheet and complete Hit Points, native class progression, subclass choices, features, spells, replacements, Feats, ASI +2, Epic Boons, and final review.

When a native Class, Subclass, or class-linked Feature makes an existing class spell Always Prepared, Character Builder preserves one canonical spell Item, records both acquisition origins, and reports the grant in Review. Limited-list casters receive the normal spell choice that was released. Paladin's Smite remains a separate Feature while its native ItemGrant augments the single Divine Smite spell with the free-cast use and forwarding Activities.

Character Keeper and Rest Management

When a character has an optional supported Short or Long Rest action, Character Keeper opens before the rest completes. The player may manage the class feature or continue the rest without changing anything. Normal D&D5e recovery and runtime mechanics remain native to the system.

For Cleric, Druid, Paladin, and Wizard, the GM can let Character Keeper own ordinary Long Rest spell preparation. While enabled, players prepare those spells in the Keeper and cannot toggle them directly on the sheet; disabling the option restores native manual preparation. Player Sheet Integrity separately offers Allow Casting Unprepared Spells with On, Out of Combat Only, and Off modes, preserving Wizard Ritual Adept outside combat.

GMs may optionally enable Half Long-Rest Recovery on Short Rest. It is disabled by default. When enabled, the native Short Rest completes first, then the module restores half of eligible Long-Rest-only reserves, rounded down, subject to a configurable server-time cooldown. Native Short Rest recovery is never blocked, and every additional recovery is reported in chat.

Rules Automation Assistance

Game Masters can enable a compact world-level assistance layer for selected D&D5e rules that are not fully automated. A master switch pauses the whole service without erasing individual choices, while a dedicated configuration screen enables or disables individual rules such as fighting-style damage assistance, class spellcasting modifiers, native effect/binding support, Summon profile guards, and Weapon Mastery chat assistance.

The granular controls let a world disable only an overlapping rule when another module already automates it. Character Builder uses native roll hooks, Active Effects, enchantments, and native chat cards rather than duplicate Items, Activities, or permanent formula edits. Weapon Mastery assistance stays deliberately compact: the official D&D5e mastery link remains the rules reference, while Graze/Cleave receive only deterministic damage controls and Topple may show its final DC. No target, distance, turn, or Action Economy tracking is added.

Wizard Spellbook Tools

Eligible Wizards receive spellbook-management tools for copying written spells and Spell Scrolls. Cost, time, configured Arcana checks, and failure consequences are shown before a protected confirmation.

Protected Transactions

Character Creation, Level Up, Multiclass, Epic Boon, Character Keeper, and Scribe Spell commits use protected transactions. Background interaction and duplicate submits are blocked while the live Actor is being updated.

Content Sources and Campaign Rules

A dedicated source selector discovers compatible active module, system, and world Item compendiums automatically. Game Masters choose enabled packages, source priority, Modern D&D or 2014 progression rules, Ability Score methods, Level Up mode, multiclass rules, Feat/ASI +2/Epic Boon permissions, Hit Point methods, Starting Equipment Shop bonus gold, Wizard scribing rules, and tutorial preferences.

Modern or 2014 Progression

Modern D&D mode holds subclass selection until Class level 3, including older sources that originally selected a subclass at level 1 or 2. D&D 5th Edition (2014) mode preserves the levels authored by the source documents. The actual choices and grants remain native D&D5e Advancements.

Built-In Tutorial

Character Builder includes a role-aware multi-page tutorial for Game Masters and players. Each Foundry User has an independent display preference, and the guide can be reopened manually at any time. Game Masters may also force the appropriate tutorial to reappear once for every User.

Installation and Required Dependency

Install Character Builder from the Foundry package browser or use the manifest URL listed for this package.

Required: libWrapper 1.13.5.1 or newer. Character Builder declares libWrapper as a required relationship using its official manifest, so Foundry can resolve and install the dependency. The world cannot enable Character Builder while libWrapper is missing or inactive.

libWrapper Project: https://github.com/ruipin/fvtt-lib-wrapper

Character Builder uses libWrapper for coordinated D&D5e method interception and conflict reporting. It also avoids non-standard Array convenience methods and uses module-prefixed helpers and Application classes to reduce interference in module-heavy worlds.
